# 工作台布局

`Workbench.tsx` 组合主侧栏、编辑组、工具侧栏及运行面板。文档内容由 `WorkbenchSurface` 的稳定 Portal 容器在布局之间移动，窗口缩放和标签切换不重建文档。

`workbench-geometry.ts` 根据窗口实际可用宽高、编辑组所需空间、用户侧栏开关和已保存宽度计算显示尺寸。不再用 1200 像素强制折叠左栏，也不再用 1000 像素强制合并右栏；空间足够时保留左右侧栏和中间编辑区。适配时只约束显示尺寸，不覆盖已保存的宽度偏好；分隔线使用相同的有效范围。

空间不足时，编辑组可合并为紧凑标签，右侧工具栏则从右边覆盖展开，保留当前编辑组。工具侧栏收起后隐藏原容器，已打开扩展的 iframe 仍留在原处。没有打开的侧栏标签时，右上角按钮和快捷键直接列出可用的侧栏扩展。更窄的窗口保留左侧活动轨，文件和会话按钮可临时弹出导航内容。

`workbench.css` 按工作台实际展开状态覆盖旧聊天页的窄屏隐藏样式。展开时会话列表保持内嵌显示，角色立绘也不再受旧聊天页的独立隐藏断点影响。`Sidebar` 在已展开状态下点击活动按钮只切换内容，不残留弹层状态。

维护时保留文档草稿、拖动布局、账号命名空间及既有开关状态；不要为适配小窗口改写用户保存的编辑组或重新挂载角色/聊天视图。

工具侧栏本轮修改已通过 `npm run build`，包括主题检查、TypeScript 编译和 Vite 打包。桌面交互待验收。
