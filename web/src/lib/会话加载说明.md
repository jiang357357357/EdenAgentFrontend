# 会话快照加载

`session-snapshot-requests.ts` 合并同一账号、世界、运行时身份代际及请求参数下正在进行的读取。会话列表、会话摘要、消息分页及运行时 Hook 的重复模型刷新可共用进行中的请求；完成或失败立即移除，不保留已完成的历史缓存。账号、凭据或世界变化时废弃旧请求，发送前与结果返回后均核对身份。

`useSessionRuntime` 由连接打开统一启动列表和历史恢复，待审批事项并行同步。历史可以先显示，恢复完成提示仍等待审批同步；模型目录刷新独立更新模型错误状态，发送、审批和模型绑定仍由原有服务校验。

Server 在初始化成功后，仅允许 `session.list`、`session.read`、`message.list` 越过普通串行队列。它们仍经过账号复核、会话通道约束和数据归属检查，使用普通请求容量，不占用高优先级请求的保留容量。写操作继续串行。

`message.list` 的可选 `directorRuns` 字段只包含当前消息页对应轮次的编排记录，首次读取和向上翻页均适用；客户端不再为每页读取整段会话的 `director.list`。旧调用方可忽略新增字段；旧 Server 未提供该字段时显示消息而不补发全量编排查询。更早的编排记录随消息翻页补齐，合并时保留较新的实时进度。

新增 `director_runs_message_turn` 索引迁移在服务下一次正常启动时执行；源码构建本身不访问或迁移用户数据库。前后端应一起更新并重启 Agent 服务后验收。
